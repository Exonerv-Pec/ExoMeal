# ExoMeal

Планировщик питания на неделю, который работает офлайн. Нажмите одну кнопку и получите меню на неделю, которое попадает в вашу норму калорий и белка, список покупок на всю неделю и список блюд для готовки.

[English version](README.md)

> **Статус: ранняя альфа (v0.1).** Работает основное: 61 рецепт, 94 продукта, случайная генерация недели, список покупок и заготовки. Планы в [ROADMAP.md](ROADMAP.md).

## Что умеет

- **Собирает неделю.** Четыре приёма пищи в день (завтрак, обед, ужин, перекус; любой можно отключить). Каждый день попадает в норму калорий с отклонением в несколько процентов, белка хватает, блюда не повторяются день за днём.
- **Вы управляете результатом.** Закрепите блюдо, и оно останется при пересборке. Замените один приём пищи случайным, выберите блюдо сами или измените порцию с шагом в четверть.
- **Считает вашу норму.** Формула Миффлина — Сан Жеора по возрасту, росту, весу, активности и цели, с безопасным минимумом. Калории можно задать вручную.
- **Учитывает питание.** Веганство, вегетарианство, рыба без мяса; исключения (глютен, молочное, яйца, орехи, арахис, рыба, морепродукты, соя, кунжут), нелюбимые продукты и лимит времени на блюдо. Пометки «Веган» и «Без глютена» вычисляются по ингредиентам, поэтому не устаревают.
- **Список покупок.** Количества из всех блюд складываются (300 г + 200 г лука превращаются в одну строку), показываются так, как их покупают (штуки, килограммы) и группируются по отделам магазина. Масла и специи вынесены в группу «Проверьте, есть ли дома». Список можно скопировать, скачать, распечатать и отмечать купленное.
- **Заготовки.** Блюда недели собраны по рецептам с общим числом порций и приёмами пищи, для которых они нужны. По желанию обед и ужин готовятся сразу на два дня.
- **Свои рецепты и продукты.** Добавляйте рецепты и продукты с КБЖУ на 100 г.
- **Приватность.** Без аккаунта, сервера и слежки. Страница запрещает сетевые запросы (Content Security Policy). Всё хранится в браузере; резервную копию можно скачать в JSON.

## Попробовать

Откройте **https://exonerv-pec.github.io/ExoMeal/** (после первого деплоя, см. ниже). Ничего устанавливать не нужно.

### Запуск у себя

Нужен Node.js 20 или новее:

```
npm install
npm run dev        # http://localhost:5173
npm test           # тесты ядра и интерфейса
npm run check      # проверка типов
npm run build      # статический сайт в dist/
```

### Публикация на GitHub Pages

Workflow `.github/workflows/ci.yml` проверяет, тестирует и собирает проект при каждом push и pull request, а ветку `main` публикует на GitHub Pages. Один раз включите: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

## Структура

```
src/core/     Чистый TypeScript без интерфейса: единицы, питание и нормы,
              диеты, генератор недели, список покупок, хранилище
src/data/     Продукты и рецепты (обычный TypeScript, легко расширять)
src/lib/      Интерфейс на Svelte 5
tests/        Vitest: логика, проверка данных, сквозной тест интерфейса
```

Генератор детерминирован: один и тот же seed даёт одну и ту же неделю. Он создаёт много случайных вариантов и оставляет тот, что лучше всего попадает в нормы калорий и белка при минимуме повторов.

## О цифрах

Значения КБЖУ ориентировочные: собраны вручную по общедоступным справочным таблицам и служат ориентиром, а не лабораторными данными. Тест проверяет, что калорийность каждого продукта согласуется с его БЖУ. Заметили ошибку? Откройте issue или pull request.

ExoMeal не заменяет консультацию врача. Приложение рассчитано на здоровых взрослых. При беременности, хронических заболеваниях и расстройствах пищевого поведения рацион нужно составлять вместе со специалистом. Для людей младше 18 лет дефицит калорий не рассчитывается.
